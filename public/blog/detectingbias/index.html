Introduce setting: you have data on decisions on outcomes (but not necessarily a view into the exact process, or the data that they had available to them.) How would you detect bias?

Two widely used tests. Problems with each.

Formalizing model. Defining what “unbiased” decision-making looks like. Show how these two tests could each (incorrectly) identify bias. Note that they point in opposite directions.

Model and Result

A decision-maker is presented with a set of applicants. For each applicant, the decision-maker observes their group label (i.e. minority or non-minority), as well as their ‘score.’ Based on this information, the decision-maker makes a binary decision (i.e. whether to give a loan, or whether to stop the vehicle). For individuals selected by the decision-maker, we eventually observe an outcome (whether the borrower repaid the loan, whether the vehicle contained contraband).

Think of the score as an estimate of the outcome: in the bank example, it could be the probability of full repayment, or the expected amount of the loan that is repaid. Formally, we are going to assume that for each group, the scores are calibrated: among those from group \(X\) given score \(s\), the true average outcome is \(s\). (Without some constraint like this, the decision-maker could simply assign scores arbitrarily. For example, it could assign low “personality” scores to Asian applicants and then claim it was letting in everyone with sufficiently high personality scores.)

A natural policy to follow is to select all individuals whose scores are sufficiently high. A ‘biased’ policy uses different score thresholds for different groups. Could also not use a threshold – what if we have randomized thresholds? Presumably, results go through?

library(ggplot2)
plot_pdfs_with_threshold <- function(pdf1, pdf2, threshold, xmin, xmax, 
                                     color1 = "red", color2 = "blue", 
                                     name1 = "Distribution 1", name2 = "Distribution 2") {
  # Create a data frame for plotting
  x <- seq(xmin, xmax, length.out = 1000)
  df <- data.frame(
    x = x,
    density1 = pdf1(x),
    density2 = pdf2(x)
  )
  
  # Calculate conditional expectations
  conditional_expectation <- function(pdf, threshold, xmax) {
    integrate(function(x) x * pdf(x), threshold, xmax)$value / 
      integrate(pdf, threshold, xmax)$value
  }
  
  ce1 <- conditional_expectation(pdf1, threshold, xmax)
  ce2 <- conditional_expectation(pdf2, threshold, xmax)
  
  # Create the plot
  p <- ggplot(df) +
    geom_line(aes(x = x, y = density1, color = name1)) +
    geom_line(aes(x = x, y = density2, color = name2)) +
    geom_area(data = subset(df, x >= threshold), aes(x = x, y = density1, fill = name1), alpha = 0.3) +
    geom_area(data = subset(df, x >= threshold), aes(x = x, y = density2, fill = name2), alpha = 0.3) +
    scale_color_manual(values = c(color1, color2), name = "Distribution") +
    scale_fill_manual(values = c(color1, color2), name = "Distribution") +
    geom_vline(xintercept = threshold, color = "black", size = 1) +
    geom_vline(xintercept = ce1, color = color1, linetype = "dashed") +
    geom_vline(xintercept = ce2, color = color2, linetype = "dashed") +
    labs(title = "PDFs with Threshold and Conditional Expectations",
         x = "Value", y = "Density") +
    theme_minimal() +
    coord_cartesian(ylim = c(0, NA))  # Set y-axis minimum to 0
  
  return(p)
}


# Example usage with normal distributions
pdf1 <- function(x) dnorm(x, mean = 4, sd = 1)
pdf2 <- function(x) dnorm(x, mean = 5, sd = 1)
threshold <- 4

plot <- plot_pdfs_with_threshold(pdf1, pdf2, threshold, 0, 9)

Discussion: what I like is clean message, and test that could actually be used (i.e. data is available, and administrators could understand what questions are being asked). Main concerns are (i) difficulty verifying the assumption, and (ii) other definitions of bias beyond calibrated predictions. Also (iii) multiple groups. Is this as simple as turning into many binary problems and adjusting for multiple corrections?

Where do these scores come from? How are they generated?

Calibration is fairly weak: could simply pool groups to get more accepted (i.e. Columbia business school). Example: employer has applicants from CUNY and Columbia. If you estimate scores based on grades and school, employer will take more from Columbia, but some from each. If you choose not to include grades, result could be to hire nobody from CUNY and everybody from Columbia. What information you are using makes a big difference!

For example, suppose that you have a data set which consists of two variables – age and race. You try building a model with just age, and find that including race predicts better. That is, log probability of repayment is estimated to be a function of the two, and race helps to explain. From a statistical/information perspective, this could be justified. But quite literally, what this means is that some applicants receive lower scores just because they are black, and these lower scores are the reason their loan application is denied.

Eliminating the ability to use race doesn’t fully fix the issue. What if we look at something very correlated with race – i.e. neighborhood? Should we be allowed to use this? It’s hard for me to say ‘no’ (I’m inclined to say yes), but I understand why some people would find this problematic.

Example from medicine – KDPI score is lower for kidneys from black donors. (This is an aside, but an interesting one.) In what sense are KDPI scores calibrated? They are not – explicitly normalized. What is KDRI supposed to measure? Why not use KDRI instead of KDPI?
