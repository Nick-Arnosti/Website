Partitioning the US into contiguous regions using MILPs

Nick Arnosti

2024/12/25

 

This post inspired by my friend Ben Orlin, who mentioned the following problem on his blog:

Fact: the U.S. has the world’s largest economy (as measured by GDP). But let’s break the U.S. into smaller economies, and see how much of the world’s Top 10 it can thereby dominate.
Warm-up: Treating the U.S. as 51 separate economies, one for each state (plus DC), how many rank among the world’s ten largest?
Challenge: Now, consider all the ways to decompose the U.S. into new, smaller economies, each consisting of one or more contiguous states. Let’s do this to maximize the number of economies that rank in the world’s ten largest. What’s the best you can do?

Ben provides the data to get started. Outside of the US (~$28 trillion), the largest economy by far is China (~$18 trillion). Germany is in third place (~$4.7 trillion), followed by Japan (~$4.1 trillion) and India (~$3.9 trillion).

If we treat each US state as a separate country, California would just edge out Japan, putting it in third place. Texas (~$2.7 trillion) would fall behind the aforementioned countries as well as the UK and France. New York would be behind Italy and just ahead of Canada.

MILP Formulation

Let \(S\) be the set of states, with representative element \(s\), and let \(w_s\) denote the weight (in this case, GDP) of state \(s\). Let \(R\) be the set of regions, with representative element \(r\).

Consider decision variables \(x_{s,r} \in \{0,1\}\), indicating whether state \(s\) is in country \(r\). Given \(k\), we wish to choose \(x\) (that is, the regions) to maximize the GDP of the smallest region. This can be formulated as follows:

\[\begin{align*} \max & \,\,\, g \\ s.t. & \,\,\, g \le \sum_{s} w_s \cdot x_{s,r} \,\, \forall r \in R \text{ # g is smaller than the GDP of each region} \\ & \sum_{r} x_{s,r} = 1 \hspace{.48 in} \forall s \in S \text{ # each state is in one region} \\ & x_{s,r} \in \{0,1\} \hspace{.6 in} \forall s \in S, r \in R \end{align*}\]

So far so good. Unfortunately, this doesn’t require that the regions be geographically coherent! Specifically, I want them to be contiguous, meaning that from any state in a region, I should be able to walk to any other state in the region without leaving the region. To avoid annoying definitions, I will let the set of states be the lower 48 (that is, I exclude Alaska and Hawaii).

How do we actually encode this constraint? Suppose that we have an adjacency matrix \(A\), with \(A[s,s'] = 1\) if states \(s\) and \(s'\) are adjacent, and \(A[s,s'] = 0\) otherwise.

For now, I will suppose we have been given “capital states” of each region.

Create auxiliary variables \(f_{s,s',r}\), which are non-negative real numbers. The value \(f_{s,s',r}\) represents the “flow” from \(s\) to \(s'\)

\[\begin{align*} f_{s,s',r} \le x_{s,r} \\ f_{s,s',r} \le x_{s',r} \\ f_{s,s',r} \le |S| A[s,s']\\ \sum_{s'} f_{s,s',r} - f_{s',s,r} = x_{s,r} \text{ if $s$ is not the capital of $r$}\\ \sum_{s'} f_{s',s,r} = \sum_{s' \ne s} x_{s',r} \text{if $s$ is the capital of $r$} \\ \end{align*}\] The first two constraints ensure that \(f_{s,s',r}\) can be positive only if \(s\) and \(s'\) are both in region \(r\). The next constraint says that flow can only be pushed between adjacent states. The fourth constraint says that each non-capital state in the region nets one unit of outflow. Suppose we fix the regions (meaning that we fix the values of \(x\)), such that each capital is in the appropriate region. I claim that the constraints on \(f\) above are feasible if and only if each region is contiguous. First, suppose the region is not contiguous. This means that there is some state or contiguous set of states that is isolated from the capital of its region. Then the first three constraints imply that net flow for this state or set of states is zero. This should lead to a contradiction – go through it more carefully.

Conversely, suppose the region is contiguous. For each \(s\) in region \(r\), trace a path in the graph from \(s\) to the capital of \(r\). Push one unit of flow along each of these edges. Add up flows on a given edge. Claim that the resulting flows should be feasible. Check to make more precise and ensure correctness.

I think we can eliminate separate weights, and have states push their flow to the capital. Worth looking into?

However, there is a problem with this formulation: we don’t know which states to make the “capitals” in advance! We can fix this by introducing variables \(c_{s,r} \in \{0,1\}\) which are one if state \(s\) is the capital of region \(r\). \[\begin{align*} \sum_s c_{s,r} = 1 \,\, \forall r \in R\\ c_{s,r} \le x_{s,r} \,\, \forall s \in S, r \in R \\ \end{align*}\] The first constraint says that each region has exactly one capital state. The second says that in order to be the capital of a region, a state must belong to that region. Easy enough, right? Not so fast! If we go back to our constraints on \(f\) that assumed capital cities were known, we see that if \(c\) is a variable, then they are non-linear! In particular, we can write them as follows:

\[\begin{align*} (x_{s,r}-\sum_{s'} (f_{s,s',r} - f_{s',s,r})) (1-c_{s,r}) \ge 0 \\ (\sum_{s' \ne s} x_{s',r} - \sum_{s'} f_{s',s,r}) c_{s,r} \ge 0 \\ \end{align*}\] Should second constraint be net flow to \(s\), rather than just inflow?

Take a look! This correctly captures constraints, but is not linear (we have a product of \(c\) and \(x\), a product of \(c\) and \(f\)…)

Point out that we have a trick for converting this product form into an LP through use of a ``large constant” \(M\).
