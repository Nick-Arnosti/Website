Monthly batching. At the end of each month, you have a directed graph. Maximize total matches.

Let \(S\) be the set of patient-donor pairs.

Let \(C \subset S\times S\) be the set of compatible pairs. That is \((i,j) \in C\) means that the donor from pair \(i\) can give to the patient from pair \(j\). \(\color{red}{\text{Represent with compatibility graph?}}\)

We want to some up with a transplant plan \(T \subset C\). It will be convenient to let this plan be represented by a set of variables \(x[i][j] \in {0,1}\), where \(x[i,j] = 1\) means that \((i,j) \in T\) (that is, \(i\) donates to \(j\)) and \(x[i,j] = 0\) means that \((i,j) \not\in T\).

\[\begin{align} \max \sum_{i,j} x[i,j] & \text{Maximize total transplants} \\ \hspace{0.5 in} x[i,j] \le C[i,j] & \forall i,j \in S \hspace{.5 in} \text{Transplants can occur only between compatible patients and donors} \\ \hspace{0.5 in} \sum_{j} x[i,j] \le 1 & \forall i \in S \hspace{.5 in} \text{Each donor can give to at most one recipient} \\ \hspace{0.5 in} \sum_{j} x[j,i] \le 1 & \forall i \in S \hspace{.5 in} \text{Each patient can receive from at most one donor} \\ \hspace{0.5 in} \sum_{j} x[i,j] \le \sum_{j} x[j,i] & \forall i \in S \hspace{.5 in} \text{Each donor gives only if their patient receives} \\ \end{align}\]

This is an integer programming problem with linear constraints and objectives. \(\color{blue}{\text{Natural question: if we relax integrality constraint, is it naturally integral? Intuitively and based on simulations, yes. But total unimodularity is a total mystery to me.}}\)

We have the following neat observation: if \(M\) is a perfect matching in the bipartite graph \((D,P)\) (meaning that every vertex in \(M\) is matched), then \(M\) corresponds to a set of disjoint cycles in \(G\). Let’s do an example.

In practice, it’s illegal to write a contract involving the donation of a kidney. Thus, if patient A receives a kidney before donor A gives one, donor A could in theory back out of any planned donation with no ramifications. For this reason, cycles are generally completed using simultaneous surgeries. A two-way exchange requires four surgical teams and operating rooms. A three-way exchange requires six surgical teams. For this reason, most exchanges limit the length of cycle that can be used.

Let’s start with the case of 2-way cycles. We can modify the program above to add the following constraint: \[\begin{equation} x[i,j] = x[j,i] \end{equation}\] This enforces that we can only do 2-cycles by requiring that if \(i\) donates to \(j\), then \(j\) donates to \(i\).

Now, the relaxation into a linear program is definitely not integral. Consider the following example, with three pairs. Any donor can donate to both of the other patients. Because there are only three pairs and we are restricted to two-way exchanges, the best we can do is match two of the three pairs.
